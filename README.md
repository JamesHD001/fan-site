# KEANU REEVES — The Official Fan Community Experience

A full-stack celebrity fan-community platform developed as a student software engineering project.

## Project Structure

- `frontend/` — React + Vite client application
- `server/` — Express REST API and backend services
- `database/` — Database seed data and scripts
- `docs/` — Project documentation

## Technology Stack

### Frontend

- React
- Vite
- React Router
- Axios

### Backend

- Node.js
- Express
- MongoDB
- Mongoose

### Payment

- Paystack
